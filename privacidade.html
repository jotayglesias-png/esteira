Política de Privacidade

Última atualização: 1 de setembro de 2026

A Esteira é uma ferramenta de uso privado. Ela opera exclusivamente sobre canais do YouTube pertencentes ao próprio operador, e não coleta dados de terceiros.

1. Quem opera o aplicativo

O aplicativo "Esteira" é operado por João Prata, que também é o titular das contas Google e dos canais do YouTube nos quais a ferramenta atua. Contato: jotayglesias@gmail.com.

O aplicativo não tem cadastro, não tem interface pública e não é oferecido a terceiros. Nenhum usuário além do operador se autentica no aplicativo: as únicas contas Google que passam pelo fluxo de consentimento OAuth são as do próprio operador, titulares dos canais em que a ferramenta atua.

2. Dados que o aplicativo acessa

Mediante autorização explícita da conta Google do operador no fluxo de consentimento OAuth, o aplicativo solicita três escopos das APIs do YouTube, e nada além deles:

  • https://www.googleapis.com/auth/youtube.upload — enviar vídeos aos canais do operador;
  • https://www.googleapis.com/auth/youtube — gerir os vídeos e as miniaturas dos canais do operador (título, descrição, tags, miniatura, agendamento) e ler os dados desses mesmos canais: lista de vídeos, conteúdo das playlists e estatísticas públicas do canal;
  • https://www.googleapis.com/auth/youtube.force-ssl — publicar comentários nos vídeos dos próprios canais do operador.

O aplicativo não solicita escopos de relatórios do YouTube Analytics. Também não acessa e-mail, contatos, arquivos, agenda, localização ou qualquer outro dado da Conta do Google fora dos escopos acima.

3. Para que os dados são usados

Os dados são usados apenas para executar as tarefas que o operador solicita nos seus próprios canais:

  • enviar vídeos já produzidos;
  • preencher ou corrigir título, descrição, tags, miniatura e agendamento;
  • ler a lista de vídeos, o conteúdo das playlists e as estatísticas públicas do canal, para controle interno de produção;
  • publicar um comentário nos vídeos do próprio canal, quando o operador assim determina.

O aplicativo não cria nem altera playlists — o acesso a playlists é somente de leitura. O aplicativo não manipula legendas. O aplicativo não comenta, não responde e não interage em vídeos ou canais de terceiros.

Os dados não são vendidos, alugados, cedidos, usados para publicidade, usados para treinar modelos de inteligência artificial, nem compartilhados com terceiros para qualquer finalidade.

4. Armazenamento e retenção

O aplicativo armazena apenas duas coisas:

  • Tokens OAuth de atualização (refresh tokens) emitidos pelo Google para as contas do operador. Ficam em arquivo no servidor privado do operador, com permissão de sistema de arquivos 0600 (leitura e escrita apenas pelo dono do processo), e são usados exclusivamente para autenticar as chamadas às APIs do YouTube.
  • Estatísticas públicas dos canais do próprio operador — número de inscritos, visualizações, contagem de vídeos, títulos e datas de publicação — gravadas em um arquivo JSON local que é sobrescrito a cada execução, servindo apenas ao acompanhamento interno de produção.

O aplicativo não armazena dados de espectadores, dados pessoais de terceiros, comentários de terceiros nem conteúdo de vídeos de terceiros. Não há banco de dados de usuários, porque não há usuários além do operador.

Quando uma autorização é revogada, os tokens correspondentes deixam de funcionar e são descartados. Os arquivos locais podem ser apagados pelo operador a qualquer momento.

5. Uso das APIs do YouTube

Este aplicativo usa os Serviços de API do YouTube. Ao autorizá-lo, aplicam-se os Termos de Serviço do YouTube e a Política de Privacidade do Google.

O uso que a Esteira faz das informações recebidas das APIs do Google obedece à Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

6. Como revogar o acesso

A autorização concedida a este aplicativo pode ser revogada a qualquer momento, sem aviso prévio, em https://myaccount.google.com/permissions. A revogação interrompe imediatamente qualquer acesso do aplicativo aos dados daquela conta.

7. Segurança

O acesso ao ambiente onde a ferramenta é executada é restrito ao operador. As credenciais não são compartilhadas nem versionadas em repositórios públicos.

8. Alterações nesta política

Alterações relevantes serão publicadas nesta mesma página, com atualização da data no topo.

9. Contato

Pedidos de esclarecimento, correção ou exclusão de dados: jotayglesias@gmail.com.
