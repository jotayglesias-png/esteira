Privacy Policy

Last updated: 1 September 2026

Esteira is a private-use tool. It operates exclusively on YouTube channels owned by the operator himself, and it does not collect data from third parties.

1. Who operates the application

The "Esteira" application is operated by João Prata, who is also the holder of the Google accounts and the owner of the YouTube channels on which the tool acts. Contact: jotayglesias@gmail.com.

The application has no sign-up, no public interface and is not offered to third parties. No user other than the operator authenticates into the application. The only Google accounts that ever go through the OAuth consent flow are the operator's own accounts, which own the channels the tool acts upon. There are no end users, no customers and no third-party channels.

2. Data the application accesses (OAuth scopes)

With the explicit authorisation of the operator's Google account through the OAuth consent flow, the application requests three YouTube API scopes, and nothing beyond them:

  • https://www.googleapis.com/auth/youtube.upload — to upload videos to the operator's own channels;
  • https://www.googleapis.com/auth/youtube — to manage the videos and thumbnails of the operator's own channels (title, description, tags, thumbnail, scheduling) and to read data from those same channels: the video list, the contents of playlists, and public channel statistics;
  • https://www.googleapis.com/auth/youtube.force-ssl — to publish comments on videos of the operator's own channels.

The application does not request any YouTube Analytics reporting scope. It also does not access email, contacts, files, calendar, location or any other Google Account data outside the scopes listed above.

3. What the data is used for

The data is used only to carry out the tasks the operator requests on his own channels:

  • upload already-produced videos;
  • set or correct title, description, tags, thumbnail and scheduling;
  • read the video list, the contents of playlists and the channel's public statistics, for internal production tracking;
  • publish a comment on videos of the operator's own channel, when the operator decides to do so.

The application does not create or modify playlists — playlist access is read-only. The application does not handle captions or subtitles. The application does not comment on, reply to or interact with third-party videos or channels.

The data is not sold, rented, transferred, used for advertising, used to train artificial-intelligence models, nor shared with third parties for any purpose whatsoever.

4. Storage and retention

The application stores only two things:

  • OAuth refresh tokens issued by Google for the operator's accounts. They are kept in a file on the operator's private server, with filesystem permission 0600 (read and write by the owner of the process only), and are used exclusively to authenticate calls to the YouTube APIs.
  • Public statistics of the operator's own channels — subscriber count, view count, video count, video titles and publication dates — written to a local JSON file that is overwritten on every run, used only for the operator's internal production tracking.

The application does not store viewer data, personal data of third parties, third-party comments, or the content of third-party videos. There is no user database, because there are no users other than the operator.

When an authorisation is revoked, the corresponding tokens stop working and are discarded. The local files can be deleted by the operator at any time.

5. Use of the YouTube APIs

This application uses the YouTube API Services. By authorising it, the YouTube Terms of Service and the Google Privacy Policy apply.

Esteira's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. How to revoke access

The authorisation granted to this application can be revoked at any time, without prior notice, at https://myaccount.google.com/permissions. Revocation immediately stops any access by the application to that account's data.

7. Security

Access to the environment where the tool runs is restricted to the operator. Credentials are not shared and are not committed to public repositories.

8. Changes to this policy

Relevant changes will be published on this same page, with the date at the top updated accordingly.

9. Contact

Requests for clarification, correction or deletion of data: jotayglesias@gmail.com.

Esteira — private use.
